Piyoko for Windows
Version 1.0.0

「小さないのちと、やさしい毎日を。」

============================================================
1. 起動方法
============================================================

1) ダウンロードしたZIPを任意の場所へ展開してください。
2) 展開した Piyoko フォルダを開いてください。
3) Piyoko.exe をダブルクリックしてください。

このゲームはインストール不要です。
インターネットへ接続せず、オフラインで遊べます。

Windowsから保護に関する確認が表示された場合は、入手元とファイル名が
正しいことを確認したうえで起動してください。

============================================================
2. ゲームの始め方
============================================================

・最初から
  新しい育成を開始します。たまごをタッチするとピヨコが生まれます。

・続きから
  保存されている育成データから再開します。
  育成中のデータがない場合は選択できません。

============================================================
3. 基本操作
============================================================

・ごはん
  食べ物を選びます。食べ物によってステータスへの効果が異なります。

・なでる
  なかよしときげんを上げます。

・あそぶ
  ミニゲームを始めます。途中で「あそびをやめる」こともできます。

・おてつだい／おしごと
  おなかときげんを消費し、ショップで使えるCを獲得します。

・ショップ
  Cを使ってアイテムを購入します。
  購入したアイテムは「もちもの」から使用できます。

・ピヨコ図鑑
  発見したピヨコの姿、説明、進化条件を確認できます。

・おもいで
  育成を終えたピヨコの記録を確認できます。

大人ピヨコへ成長すると「育成をおえる」が表示されます。
育成を終えると記録がおもいでへ保存され、次のたまごを育てられます。

============================================================
4. セーブについて
============================================================

ゲームは、お世話や画面移動などのタイミングで自動保存されます。

Windowsでの通常の保存場所：

  %APPDATA%\Godot\app_userdata\Piyoko

保存される主なファイル：

  piyoko_save.json        現在育成中のピヨコ
  piyoko_collection.json  図鑑
  piyoko_memories.json    おもいで
  piyoko_economy.json     所持C・もちもの
  piyoko_settings.cfg     音量・画面設定

別のPCへ移行する場合は、ゲームを終了してから上記フォルダをコピーしてください。

============================================================
5. 設定・データ削除
============================================================

タイトル画面の設定から、音量とフルスクリーン表示を変更できます。

「完全初期化」は、育成・図鑑・おもいで・所持C・もちものなどを削除します。
削除したデータは元に戻せません。

============================================================
6. アンインストール
============================================================

展開した Piyoko フォルダを削除してください。

セーブデータも削除する場合は、次のフォルダも削除してください。

  %APPDATA%\Godot\app_userdata\Piyoko

============================================================
