# itch.io掲載内容

## タイトル

Piyoko

## 短い説明

ぴよこをお世話して、いろいろな姿へ育てる育成ゲーム。

## 紹介文

ぴよこにごはんをあげたり、なでたり、いっしょに遊んだりしながら成長を見守る育成ゲームです。

お世話の内容やステータス、使用したアイテムによって進化する姿が変わります。育てたぴよこは図鑑とおもいでに記録されます。

インターネット接続なしで遊べます。

## 対応版

- Windows 11 x64
- Android arm64

## ダウンロード設定

| ファイル | itch.ioのOS設定 | 種類 |
|---|---|---|
| `Piyoko-Windows-x64-v1.1.0.zip` | Windows | Executable |
| `Piyoko-Android-arm64-v1.1.0.apk` | Android | Executable |

## インストール方法

### Windows

ZIPを展開し、フォルダ内の `Piyoko.exe` を起動してください。Windowsの保護画面が表示された場合は、入手元とファイル名を確認してから実行してください。

### Android

APKをダウンロードして開きます。初回のみ、ブラウザからのアプリのインストール許可を求められる場合があります。

旧版から更新する場合は、先にアンインストールせず、そのまま新しいAPKを開いてください。上書きできない場合は署名が異なるため再インストールが必要ですが、旧版のセーブデータは削除されます。

- カバー画像を設定
- スクリーンショットを3～5枚設定
- YouTubeトレーラーURLを設定
- Windows ZIPとAndroid APKをアップロード
- OS設定が各ファイルに付いていることを確認
- 公開範囲を「限定公開」または「公開」に設定
