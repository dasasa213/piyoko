# Piyoko

「小さないのちと、やさしい毎日を。」をテーマにした、オフラインのピヨコ育成ゲームです。

ごはん、なでる、あそぶ、おてつだい／おしごとを通してピヨコを育てます。お世話の内容、ステータス、使用したアイテムによって成長先が変化します。育成したピヨコは図鑑とおもいでに記録されます。

## 動作環境

- Windows 11 x64
- キーボードとマウス、またはタッチ操作
- インターネット接続不要

Windows版はGodot 4.7.2のWindows Desktopエクスポートで作成しています。

## Windows版の起動

1. 配布ZIPを任意の場所へ展開します。
2. 展開したフォルダ内の `Piyoko.exe` を起動します。
3. 初回は「最初から」を選び、たまごをタッチします。
4. 育成中のデータがある場合は「続きから」で再開できます。

配布ZIPの詳しい説明は、同梱する `README.txt` を確認してください。

## 基本操作

- ごはん：食べ物を選び、ステータスと成長履歴を変化させます。
- なでる：なかよしときげんを上げます。
- あそぶ：ミニゲームの成功・失敗を成長履歴に記録します。
- おてつだい／おしごと：おなかときげんを消費して、ショップで使えるCを獲得します。
- ショップ：ステータスアイテムや進化アイテムを購入・使用します。
- ピヨコ図鑑：発見した成長形態、説明、進化条件を確認します。
- おもいで：育成を終えたピヨコの記録を確認します。

大人ピヨコへ成長すると「育成をおえる」が表示されます。育成を終えると、そのピヨコはおもいでへ保存されます。

## セーブデータ

操作後や画面移動時に自動保存されます。Windowsでは通常、次のフォルダに保存されます。

```text
%APPDATA%\Godot\app_userdata\Piyoko
```

主な保存データ：

- `piyoko_save.json`：現在育成中のピヨコ
- `piyoko_collection.json`：図鑑
- `piyoko_memories.json`：おもいで
- `piyoko_economy.json`：所持C・もちもの
- `piyoko_settings.cfg`：音量・画面設定

タイトル画面の設定から完全初期化すると、育成・図鑑・おもいで・所持品などのデータを削除できます。

## 開発環境

- Godot 4.7.2
- GDScript
- GitHub Actionsによる自動テストとWindowsビルド

主要データはJSONで管理しています。

- `data/piyoko_forms.json`：成長形態と進化条件
- `data/shop_items.json`：ショップ商品
- `data/foods.json`：食べ物

定義の追加方法は [data/README_ja.md](data/README_ja.md) を確認してください。

## テスト

- Windows 11 x64向けリリースビルド
- 配布フォルダの構成確認
